Legend in the Mist - Printer Friendly Sheets

Character sheets and action cards for Legend in the Mist, designed to be useful at the table and cheap to print: no background art or textures, just clear boxes and plenty of room to write. Available in English and Italian (in italiano: "Scheda del Personaggio", "Carte Azione" e lo zip "it-html").

Everything here is built automatically from the GitHub repository, so the downloads are always the latest version. The repo also has the source, if you want to change or translate the sheets.

What's included

  • Character Sheet: standard, with scratchmarks (彡) in the checkboxes, or with clean empty checkboxes. A4.
  • Action Cards: 9 reminder cards per page at trading-card size (63 × 88 mm, like Magic or Pokémon cards). Write an action (Attack) and the tags you use for it (Sword, Mighty…). A4 or Letter.
  • PDFs of every sheet, ready to print, and a zip of HTML files per language, including web-fillable versions you can type into in your browser before printing.

Features

  • Printer-Friendly: black, white and grey only.
  • Clear Layout: generous line spacing for handwriting.
  • Browser-Native: the HTML files open in any browser, with nothing to install.
  • Same look everywhere: the fonts are built in, so the sheets print the same on any computer.

How to print

  • PDFs: print at 100% scale ("Actual size", not "Fit to page").
  • HTML: open the file in your browser and press Ctrl+P (Cmd+P on Mac).
  • Action Cards: pick the matching paper size, set margins to None and scale to 100%, then cut along the dashed lines.
