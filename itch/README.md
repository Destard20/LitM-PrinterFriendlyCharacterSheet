# itch.io page

Text for the [itch.io page](https://destard20.itch.io/litm-printerfriendlysheets). itch.io has no API for editing a page's text, so it's kept here and pasted by hand:

* `page.html`: the page description. Open it in a browser, copy everything below the grey box, and paste it into the description on the itch.io "Edit game" page.
* `devlog-v2.0.html`: a suggested devlog post for this update, pasted the same way.

Suggested page title: **Legend in the Mist - Printer Friendly Sheets**.

The downloads themselves are uploaded automatically by `tools/publish_itch.py` (see the main README).
